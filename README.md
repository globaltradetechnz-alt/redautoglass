# Red Auto Glass 红色汽车玻璃 — 奥克兰华人汽车玻璃专家（中文网站）

奥克兰华人社区的挡风玻璃与汽车玻璃更换维修中文网站。

- 🌐 计划域名：www.redautoglass.co.nz
- 📞 中文服务热线：0800 757-985
- 🕐 营业时间：每天早上7点 – 晚上11点（每周7天）
- 📍 地址：133 Pilkington Road, Panmure, Auckland 1072

## 网站页面

| 页面 | 说明 |
|---|---|
| `index.html` | 首页：服务、品牌、评价、保险、覆盖区域、FAQ、询价 |
| `services.html` | 四大服务项目详解 + 特斯拉/揽胜专家 |
| `insurance.html` | 保险理赔流程与 36+ 家合作保险公司 |
| `about.html` | 品牌故事与门店信息 |
